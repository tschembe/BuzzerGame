# مسابقه اطلاعات عمومی (BuzzerGame)

یک بازی مسابقه‌ای به سبک «جئوپاردی» برای اجرای گروهی، کاملاً فارسی و بدون نیاز به سرور.

## اجرا
فایل `index.html` را در مرورگر باز کنید (یا با `python3 -m http.server` سرو کنید).

## روند بازی
1. تیم‌ها را اضافه کنید (حداقل دو تیم) و «شروع بازی» را بزنید.
2. جدول ۸ دسته × ۵ سوال (۲۰۰ تا ۱۰۰۰ امتیاز) نمایش داده می‌شود.
3. روی هر خانه کلیک کنید تا سوال با زمان‌سنج ۳۰ ثانیه‌ای نمایش داده شود.
4. «نمایش جواب» را بزنید و انتخاب کنید کدام تیم درست جواب داده تا امتیاز به آن تیم برسد.
5. وقتی همه‌ی سوال‌ها تمام شد (یا با دکمه‌ی «پایان بازی»)، برنده اعلام می‌شود.

وضعیت بازی در مرورگر ذخیره می‌شود و با رفرش صفحه از بین نمی‌رود.

سوال‌ها در `js/questions.js` قرار دارند و به‌راحتی قابل ویرایش‌اند.
